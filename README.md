### Prerequisites

Make sure the following are installed on your system:
* Git
* Docker
* Docker Compose
* Make (optional) – for simplified build commands

### Starting the Application
1. Clone the Repository
```
git clone https://github.com/fallen-fatalist/esports_booking_system.git
cd esports_booking_system
```
2. Start the Application with Docker Compose
```
docker-compose up -d
```

3. (Alternative) Start Using Makefile
```
make rebuild
```
  
### Accessing the Frontend

Once up, access the app via:
```
http://localhost:3000  # or the port you've configured

```
